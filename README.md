## Engineering approach

- **Keep evidence close to the output.** Connect extracted data, retrieved passages, and explanations to the source a person can inspect.
- **Design for interruption.** Use durable queues, stable identifiers, explicit acknowledgements, and recoverable workflow state.
- **Make verification repeatable.** Build reproductions, evaluation fixtures, and executable checks alongside the application.
- **State the limits.** Document what is implemented, what has been measured, and what still needs validation.
